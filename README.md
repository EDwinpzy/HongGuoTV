# 红果短剧 · Android TV

红果短剧的**非官方** Android TV 客户端，使用 Kotlin、原生 View 和 Media3 构建，界面采用 Apple TV / iOS 风格的深色玻璃面板与紧凑布局。安装一个 APK 即可浏览和播放，不依赖自建服务器。最低支持 Android 7.0（API 24）。

> 本项目不是红果短剧官方产品，也不代表内容平台。内容来自第三方公开接口，可用性可能随接口、签名或地区网络变化而变化。

## 功能

- 遥控器方向键、OK、物理返回键导航，卡片和按钮提供可见焦点；界面内不设返回按钮
- 紧凑 7 列内容网格与固定 2:3 竖向矩形海报，搜索结果与首页使用相同的卡片尺寸
- 首页货架、独立“推荐”页（登录后账号推荐，未登录三类热门混排；每次切入都重新请求一批、不复用上次列表，进入即自动播放；预览始终显示顶部标签菜单和底部片名/简介，↑/↓换片，←/→按顶部标签顺序切页，OK 进入正常播放器）、搜索和总榜/真人剧/漫剧/AI 剧排行榜
- TV 字母键盘与系统输入法搜索，支持拼音首字母联想
- 480P / 720P / 1080P 分辨率上限选择，播放条和侧栏显示实际解码尺寸与片源码率；支持暂停、快进/后退、倍速、自动连播和断点续播
- 普通播放中 `↑` / `↓` 切换上一集 / 下一集；正常播放器隐藏顶部频道标签，空闲时后台滚动预取后续最多 20 集（前 3 集优先，远端节流），OK 呼出 VideoPro 风格播放条（片名、单行简介、进度、播放键，右侧集数），MENU 打开选集侧栏
- 弹幕显示真实评论并按文本去重；按服务端分页游标持续拉取，短暂请求失败或连接卡住时自动重试，同一集内不重复，也不在弹幕稀疏时循环重放旧评论
- 选集面板、收藏、观看进度、搜索历史和“接着看”
- 红果账号仅使用手机 App 扫码登录；启动和前台使用期间自动同步云端观看历史、播放进度、收藏与预约，无需手动刷新
- 可选手机扫码输入与局域网记录备份；只在对应窗口打开时临时监听局域网，结束后停止

自动更新已关闭。升级请从本仓库的 Releases 手动下载 APK 覆盖安装。

## 下载与安装

从 [Releases](https://github.com/EDwinpzy/HongGuoTV/releases/latest) 下载签名 APK，在 Android TV 或投影仪上侧载安装。升级时使用与已安装版本相同的签名，否则 Android 会拒绝覆盖安装。

## 构建

环境：

- JDK 17 或更高版本（已在 JDK 21 上验证）
- Android SDK Platform 35、Build Tools 35.0.0
- Gradle 8.14.3 包装器（仓库已包含）

在根目录创建 `local.properties`：

```properties
sdk.dir=C:\\path\\to\\Android\\Sdk
```

Debug 构建：

```powershell
.\gradlew.bat :app:assembleDebug
```

验证与正式构建：

```powershell
.\gradlew.bat :core:test :app:lintVitalRelease :app:assembleRelease
```

产物：

- Debug：`app/build/outputs/apk/debug/app-debug.apk`
- Release：`app/build/outputs/apk/release/app-release.apk`

Release 签名读取根目录的 `keystore.properties`，其 `storeFile` 指向本地 keystore。签名材料已被 `.gitignore` 排除，不能提交。

## 工程结构

- `core/`：纯 Kotlin 内容接口、搜索、签名、播放地址解析和媒体处理；可在 JVM 中测试
- `app/`：Android TV 界面、遥控器焦点、本地记录、Media3 播放器

## 验证与限制

已在 JMGO S621（Android 13，1920×1080）上通过 ADB 注入方向键、OK、菜单和媒体键，验证 iOS 风格首页、7 列短剧网格、搜索与结果、设置、榜单首次加载及滚动追加；海报固定为 2:3 矩形，搜索结果与首页卡片尺寸一致。2026-11-21 的 `1.1.14` 包沿用 `video_tab` v5 取流和有限预算，并把服务端真实码率接入选流与 HUD：同一分辨率优先高码率源，播放条显示 `1080P · 1922×1080 · 片源码率 508 kbps` 一类的实际参数。推荐预览保留顶部标签和底部片名/简介，按 OK 后进入无顶部标签的正常播放器。弹幕请求增加 8 秒调用超时和有界退避重试，不再因连续失败或连接挂住而静默停止。部分新剧只有单一低码率 1080P HEVC 档，官网完整 H264 兜底可能返回 403，因此最终锐度仍受服务端片源限制。**尚未使用物理遥控器按键验证**；数小时连续播放、全部 1000 集、更多 TV 型号和不同芯片解码能力仍待验证。详细记录见 [docs/VERIFICATION.md](docs/VERIFICATION.md)。
